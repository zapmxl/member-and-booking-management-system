# Σύστημα Διαχείρισης Μελών και Κρατήσεων

## Εισαγωγή

Αυτό το έργο αποτελεί μια υλοποίηση ενός συστήματος διαχείρισης μελών και κρατήσεων για έναν οργανισμό που προσφέρει πολιτιστικές και αθλητικές δραστηριότητες. Το σύστημα επιτρέπει τη διαχείριση μελών, συνδρομών, δραστηριοτήτων, προγραμμάτων και κρατήσεων.

## Οδηγίες Εκτέλεσης

### Προαπαιτούμενα

- **Java Development Kit (JDK) 8 ή νεότερη έκδοση.**
- Ένα IDE όπως το **IntelliJ IDEA** ή το **Eclipse** (προαιρετικό).

### Βήματα

1. **Κατεβάστε τον κώδικα:**

   - Κατεβάστε όλα τα αρχεία `.java` και τοποθετήστε τα σε ένα φάκελο με το όνομα `src`.

2. **Μεταγλώττιση του κώδικα:**

   - Ανοίξτε ένα τερματικό ή τη γραμμή εντολών.
   - Μεταβείτε στον φάκελο `src`.
   - Εκτελέστε την εντολή:
     ```bash
     javac *.java
     ```
     Αυτό θα μεταγλωττίσει όλα τα αρχεία Java.

3. **Εκτέλεση του προγράμματος:**

   - Εκτελέστε την εντολή:
     ```bash
     java TestMain
     ```
     Αυτό θα εκτελέσει την κύρια κλάση και θα εμφανίσει τα αποτελέσματα στο τερματικό.

## Δομή του Έργου

- **src/**: Φάκελος που περιέχει τα αρχεία κώδικα Java.
  - `PackageOption.java`: Enum για τα πακέτα συνδρομής.
  - `Member.java`: Κλάση για τα μέλη.
  - `Subscription.java`: Κλάση για τις συνδρομές.
  - `Activity.java`: Κλάση για τις δραστηριότητες.
  - `Schedule.java`: Κλάση για τα προγράμματα.
  - `Reservation.java`: Κλάση για τις κρατήσεις.
  - `ReservationManager.java`: Κλάση για τη διαχείριση κρατήσεων.
  - `TestMain.java`: Κύρια κλάση για τη δοκιμή του συστήματος.

- **docs/**: Φάκελος που περιέχει την τεκμηρίωση και τα διαγράμματα.
  - `Documentation.pdf` ή `Documentation.docx`: Αναλυτική τεκμηρίωση του έργου.
  - `ClassDiagram.png`: Διάγραμμα κλάσεων του συστήματος.

Αυτό το έργο αναπτύχθηκε ως μέρος μιας άσκησης για τη δημιουργία ενός συστήματος διαχείρισης μελών και κρατήσεων, χρησιμοποιώντας αντικειμενοστραφή προγραμματισμό στην Java.
